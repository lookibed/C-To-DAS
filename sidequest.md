# C-To-DAS — Sidequests (daslang core-language follow-ups)

Language features c2das wants that are good for daslang regardless. Each is its own arc in
the daslang repo, on its own schedule; **c2das never blocks on any of them** — every entry
has a working, probed fallback. This file exists for visibility; the plan's §13 points here.

| Sidequest | Motivation | c2das fallback until landed |
|---|---|---|
| `[pack(N)]` struct annotation | C `#pragma pack`/`__attribute__((packed))` structs become natively representable (C has no inheritance — struct layout is the whole story); WAD-style disk structs stop being marshal-only | marshal-only types via sidecar (generated byte readers/writers from clang's packed offsets) |
| `[align_as(N)]` | `_Alignas` / `__attribute__((aligned))`; also the clean storage-alignment source for `[c_union]` backing fields | marshal-only / max-align-member storage type; ignore where semantics allow |
| Native width-bitfields | das `bitfield` today = named single bits; widths + signedness would delete the `[c_bitfields]` property-operator layer AND its interp per-access call cost | property-operator emulation (probed, C-exact, works today) |
| Native `setjmp`/`longjmp` "as is" (rides with `[pack()]`) | one das exception mode already implements panic via setjmp/longjmp — exposing it directly deletes the try/recover + `_c_jmp_target` protocol and its target-check overhead | try/recover lowering (probed: multi-level targeted jumps, value passing, genuine-panic pass-through) |
| Missing typeinfo traits as trait MACROS | `is_floating_point` doesn't exist (only `is_float`/`is_double`); das has typeinfo macros — composite traits belong there, extensible without touching the compiler. Also the robust answer to `typename` reflecting the binding's constness (ordinary das rules: non-`var` param fields are `"float const"`, `var` param fields `"float"` — both probed 2026-08-21), which makes string-comparing it brittle; bool traits are qualifier-immune (NOT a static_if folding bug — string compares fold fine) | spell out per-type bool traits (probed) |
| `[inline]` on property operators | rejected today ("call sites do not splice") — allowing it removes the interp per-access call cost of emulated bitfields and unions (Lua `TValue` is the hot case) | accept the call in interp; JIT/AOT inline anyway |
| Quiet `exit()` (candidate, pending P1 check) | daslang prints exit diagnostics + call stack + atexit env warning on `exit(code)` — noise for suite runners if it lands on stdout | harness diffs stdout only (if the noise is stderr, no sidequest needed) |
